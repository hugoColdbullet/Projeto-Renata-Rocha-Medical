# Resultados do projeto

- [x] **Página HTML e identidade médica:** website institucional em HTML, de página única, para Renata Rocha — Médica Especialista em Anestesiologia; estilo inspirado na profissão; design responsivo para computador, tablet e telemóvel; cabeçalho com nome, especialidade e navegação por âncoras; apresentação com mensagem profissional e chamada à ação.
- [x] **Conteúdo profissional e especialidade:** área Sobre para biografia, formação e abordagem clínica; secção dedicada à Anestesiologia e aos principais contextos de atuação; dados profissionais não fornecidos identificados sem inventar qualificações, instituições, fotografia, resultados ou testemunhos; imagem conceptual identificada.
- [x] **Contactos e interações:** área de contacto com informações profissionais e formulário; formulário com validação, sem recolha de informação clínica sensível, sem armazenamento e sem simular envio quando não há destino; menu móvel acessível; perguntas frequentes expansíveis; rodapé com identificação e ligações relevantes.
- [x] **Entrega e expansão:** estrutura HTML semântica e organizada para facilitar a adição posterior de novas páginas; restantes páginas apenas posteriormente; ficheiros HTML, CSS e JS editáveis com instruções; página servida em Preview; versão guardada e projeto HTML transferível.

## Evidências

Diagnósticos HTML/CSS/JS/JSON/TS registados na plataforma.
